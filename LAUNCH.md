# Публикация — финальный старт под своим доменом

Не путать с деплоем. **Деплой** — автоматический: каждый пуш в `main` Vercel
выкатывает сайт (сейчас на служебном домене Vercel, реальные пользователи его
де-факто не видят). **Публикация** — разовый старт под своим доменом, когда
на сайт пойдёт настоящий трафик. Этот файл — только про публикацию.

Технический чек-лист каждого деплоя (переменные окружения, защита деплоев,
лимит Neon, быстрая проверка после выкатки) — в [`DEPLOY.md`](DEPLOY.md).
Здесь то, что нельзя забыть именно на старте.

## Обязательно к запуску

- **Свой прокси на своём аккаунте proxyma.** Синхронизация каталога в GitHub
  Actions ходит на CarClick через прокси (CarClick блокирует IP Actions).
  Сейчас используется пакет, реквизиты которого пришли в чат и лежат в секрете
  репозитория `PROXY_URL`, — это временно и не наш аккаунт. К публикации нужен
  собственный оплаченный пакет; обновить секреты `PROXY_URL` и `PROXY_EXPIRES`.
  - Прокси нужен ТОЛЬКО из-за GitHub Actions: с обычного российского IP API
    CarClick отвечает `200` без прокси. Альтернатива — перенести синхронизацию
    на свой РФ-сервер (cron + python), тогда прокси не нужен вовсе, и пропадает
    и статья расходов, и регулярная поломка «пакет кончился». Решить до старта:
    свой прокси или свой сервер.

- **Свой домен и DNS.** `www.tiglev.com` пока отдаёт старый Apache (прежний
  хостинг). На публикацию — перевести DNS на Vercel и задать
  `NEXT_PUBLIC_SITE_URL=https://tiglev.com` в Production фронта: из неё
  собираются canonical, sitemap и Open Graph.

- **Регион: Vercel iad1 vs Neon fra1.** На Hobby функции Vercel крутятся в США,
  база Neon во Франкфурте — около 100 мс на запрос. На заметном трафике
  пересмотреть (регион функций/тариф либо база ближе).

Дополнять по мере того, как всплывает то, что нельзя проглядеть на старте.
